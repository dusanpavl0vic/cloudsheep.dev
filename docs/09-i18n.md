# 09 — Internacionalizacija

> Status: active | Last review: 2026-08-15

i18next 26 + `react-i18next` + `i18next-icu` + `i18next-browser-languagedetector`.
Jezici: **`sr` (default)**, **`en`**.

## Pravila

1. **Nijedan literal string u UI-ju.** `eslint-plugin-i18next/no-literal-string` je **error**
   u `features/` i `pages/`.
2. **Namespace po feature-u** — `features/auth/locales/{sr,en}.json` → namespace `auth`.
   Globalni: `apps/<x>/src/locales/{common,errors}.json`.
3. **Ključ je `feature.section.element`.** Nikad tekst kao ključ.
4. **Svaki novi ključ ide u OBA fajla** — `sr.json` i `en.json`. CI proverava.
5. **Namespace se učitava sa feature chunk-om**, ne sav unapred.
6. **Plural i rod kroz ICU.** Srpski ima tri forme.
7. **Brojevi, datumi i valute kroz formattere** iz `@app/i18n`, nikad ručno.
8. **`<html lang>` i `dir` prate aktivan jezik** — jedan dokumentovan `useEffect`.

## Struktura

```
apps/web/src/locales/
├── common.json          # nav, dugmad, tema, jezik, footer
└── errors.json          # mrežne i validacione greške

apps/web/src/features/landing/locales/
├── sr.json              # namespace "landing"
└── en.json
```

## Type-safety

```ts
// packages/i18n/src/types.d.ts
declare module 'i18next' {
  interface CustomTypeOptions {
    defaultNS: 'common';
    resources: typeof resources;
    returnNull: false;
  }
}
```

Posledica: `t('auth.login.titl')` je **greška u kompilaciji**, ne prazan string u produkciji.

## Lazy loading namespace-a

```ts
// apps/web/src/pages/ProjectsPage.tsx
export async function loader() {
  await i18n.loadNamespaces('projects');
  return null;
}
```

Prevodi feature-a putuju sa njegovim chunk-om — landing stranica ne skida rečnik admin panela.

## ICU plural — srpski ima tri forme

Ovo je najčešći izvor grešaka. Srpski koristi `one` / `few` / `other`:

| Broj | Forma | Primer |
|---|---|---|
| 1, 21, 31, 101 | `one` | 1 projekat |
| 2–4, 22–24 | `few` | 3 projekta |
| 0, 5–20, 25–30 | `other` | 7 projekata |

```json
// features/projects/locales/sr.json
{
  "projects": {
    "count": "{count, plural, one {# projekat} few {# projekta} other {# projekata}}"
  }
}
```

```json
// features/projects/locales/en.json
{
  "projects": {
    "count": "{count, plural, one {# project} other {# projects}}"
  }
}
```

```tsx
<p>{t('projects.count', { count: projects.length })}</p>
```

**Obavezno testirati sve tri forme** — vidi checklist. Engleski ima dve; ako prekopiraš
englesku strukturu na srpski, dobićeš "3 projekat".

### Rod

```json
{ "welcome": "{gender, select, female {Dobrodošla} male {Dobrodošao} other {Dobrodošli}}, {name}!" }
```

## Formatteri

```ts
// packages/i18n/src/formatters.ts
export const formatCurrency = (value: number, locale: Locale, currency = 'EUR') =>
  new Intl.NumberFormat(locale, { style: 'currency', currency }).format(value);

export const formatDate = (date: Date, locale: Locale) =>
  new Intl.DateTimeFormat(locale, { dateStyle: 'medium' }).format(date);

export const formatRelative = (date: Date, locale: Locale) => { /* Intl.RelativeTimeFormat */ };
```

`Intl.*` je u platformi — nema `moment`-a, nema ručnog formatiranja.

## Registry jezika

```ts
// packages/i18n/src/languages.ts
export const LANGUAGES = [
  { code: 'sr', label: 'Srpski',  dir: 'ltr', dateLocale: 'sr-Latn-RS' },
  { code: 'en', label: 'English', dir: 'ltr', dateLocale: 'en-GB' },
] as const;

export type Locale = (typeof LANGUAGES)[number]['code'];
```

**Dodavanje jezika = jedan objekat u ovom nizu** + prevodi. Ništa drugo se ne menja.
Za RTL jezik (`dir: 'rtl'`) logička svojstva iz [`08-styling-ui.md`](08-styling-ui.md) rade posao.

## `<html lang>` i `dir`

```ts
// effect: document — lang/dir atributi žive van React stabla
useEffect(() => {
  document.documentElement.lang = language.code;
  document.documentElement.dir = language.dir;
}, [language]);
```

Jedan od retkih opravdanih `useEffect`-a ([`07-performance.md`](07-performance.md) §3).

## Testovi

```ts
i18n.init({ lng: 'cimode' });   // t('auth.login.title') vraća 'auth.login.title'
expect(screen.getByRole('button', { name: 'auth.login.submit' })).toBeInTheDocument();
```

**Testira se ključ, ne prevod** — inače test pada svaki put kad copywriter promeni tekst.

## Alati

```bash
pnpm i18n:extract    # i18next-parser — izvlači ključeve iz koda
pnpm i18n:check      # nedostajući / nekorišćeni ključevi, sr plural forme
```

`/i18n-check` radi isto plus traži hardkodovane stringove.

## Anti-patterns

| ❌ | ✅ |
|---|---|
| `<button>Sačuvaj</button>` | `<button>{t('common.save')}</button>` |
| `t('Sačuvaj')` — tekst kao ključ | `t('common.save')` |
| ključ dodat samo u `sr.json` | oba fajla, uvek |
| `{count} projekata` ručno | ICU plural |
| `new Date().toLocaleDateString('sr')` u komponenti | `formatDate` iz `@app/i18n` |
| kopirana engleska plural struktura na srpski | `one`/`few`/`other` |
| svi prevodi učitani na startu | namespace po feature-u, lazy |
| `t` pozvan van React-a bez namespace-a | `i18n.t('ns:key')` |

## Checklist

- [ ] Nijedan literal string — `pnpm lint` prolazi
- [ ] Ključ ima `feature.` prefiks i postoji u `sr.json` **i** `en.json`
- [ ] Novi namespace je registrovan i učitava se lazy sa feature-om
- [ ] Plural koristi ICU sa `one`/`few`/`other` za srpski
- [ ] Sve tri srpske forme pokrivene testom (1, 3, 7)
- [ ] Brojevi/datumi/valute idu kroz formattere
- [ ] `pnpm i18n:check` bez nedostajućih i nekorišćenih ključeva
- [ ] Test koristi `cimode` i proverava ključ, ne prevod
